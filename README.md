# Biomechanics and EMG Analysis in MATLAB

## About This Project

This repository contains MATLAB scripts that I have worked on for processing and analyzing biomechanical data, including EMG signals, joint kinematics, kinetics, and movement coordination.

This project reflects my practical experience with MATLAB in biomechanics research and my ongoing development of programming and data analysis skills.

## What the Code Does

The scripts include:

- Importing and organizing biomechanical data from CSV files
- Filtering and processing EMG signals
- Detecting muscle activation onset and offset
- Calculating joint angles, moments, and range of motion
- Analyzing inter-joint coordination using Continuous Relative Phase (CRP)
- Extracting movement-related parameters and exporting results

## Files

| File | Purpose |
|---|---|
| `Main.m` | Runs the main analysis workflow |
| `ReadData.m` | Reads and organizes biomechanical data |
| `FilterEMG_Q1.m` | Filters and processes EMG signals |
| `OnsetOffsetDetection.m` | Detects muscle activation timing |
| `CRP.m` | Calculates inter-joint relative phase |
| `MinaSize.m` | Resamples data using interpolation |
